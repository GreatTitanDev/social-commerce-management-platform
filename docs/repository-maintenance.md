# Repository Maintenance Guidelines

## Keep the Repository Useful
- Update files when decisions change.
- Use clear and consistent naming.
- Keep notes short and decision-oriented.
- Separate planning documents from implementation code when development starts.

## Recommended Workflow
1. Capture ideas and learnings in the appropriate folder.
2. Turn validated ideas into product or technical documents.
3. Link related documents when dependencies exist.
4. Review the repository regularly as the product evolves.
